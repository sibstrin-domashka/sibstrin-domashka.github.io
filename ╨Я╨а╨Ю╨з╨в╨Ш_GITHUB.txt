GITHUB — что делать с этим архивом

1) Распакуй архив.
2) Открой репозиторий sibstrin-domashka.github.io -> Add file -> Upload files.
3) Перетащи ВСЁ содержимое распакованной папки (файлы и папки scripts, .github, screenshots).
   Если папку .github не видно — в Windows включи «Показывать скрытые элементы» (Вид -> Показать).
4) Commit changes. Одноимённые старые файлы заменятся.

Исключение: app-config.js. Если ты уже вписывал туда своё ФИО (operatorName) —
не заменяй файл, а открой его на GitHub (Edit) и перепиши своё ФИО в новый файл перед загрузкой.
